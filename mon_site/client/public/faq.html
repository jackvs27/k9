Questions fréquentes

Comment activer le chat ?

Insérez le script chat-widget.js sur vos pages et configurez votre thème dans l'Admin.

Où sont stockées les conversations ?

Dans PostgreSQL (via la couche d'abstraction fournie) et les pièces jointes sur un stockage compatible S3.

Comment exporter les données ?

Section « Export RGPD » de l'Admin ou script CLI scripts/export_conversations.js.

Une question reste sans réponse ? Lancez le chat !
